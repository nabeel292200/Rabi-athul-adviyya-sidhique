# Rabi-athul-adviyya-sidhique

Digital Wedding Invitation for Rabi Athul Adviyya & Sidhique, crafted by Zetron Tech.

## Features
- Fully responsive mobile-first digital invitation
- Royal RS Monogram and Wax Seal interactive entrance
- Background wedding music player with auto-play handling
- Live countdown timer to the wedding reception
- Google Maps venue directions & Add to Calendar (.ics and Google Calendar)
- WhatsApp RSVP and congratulatory greetings integration

## Tech Stack
- React 19 + Vite
- Vanilla CSS design system
